# Components

## Overview

Reusable React components for the Enterprise Administration Dashboard. They provide shared layouts, dashboard widgets, application states, theming, and foundational UI controls.

## Structure

| Folder | Purpose |
| --- | --- |
| [`dashboard/`](dashboard/README.md) | Data tables, filtering and pagination controls, charts, stat cards, and loading skeletons. |
| [`layout/`](layout/README.md) | App shell, header, sidebar navigation, and page headings. |
| [`shared/`](shared/README.md) | Reusable confirmation, empty, error, and loading states; brand mark. |
| [`theme/`](theme/README.md) | Theme provider, context, hook, and light/dark/system toggle. |
| `ui/` | Low-level styled UI primitives (buttons, dialogs, forms, sidebar, charts, and more). |
